No 1 - Linked List

Buatlah sebuah kelas baru bernama ModifiedSLList yang merupakan anak (child) dari kelas SLList. Di dalam kelas baru ini, Anda perlu mengimplementasikan operator overloading di Python untuk menambahkan dua operasi khusus:

  1. Penjumlahan (+): Menggabungkan seluruh elemen linked list kedua ke akhir linked list pertama.

  2. Perkalian (*): Menggabungkan elemen dari kedua linked list secara selang-seling (interleaved).

Contoh:

print("Linked List A:")
A.print_all()

print("Linked List B:")
B.print_all()

Linked List A:

head -> 1 -> 2 -> 3 -> None

Linked List B:

head -> a -> b -> c -> d -> None

C = A+B
D = A*B

print("A+B:")
C.print_all()

print("A*B:")
D.print_all()

A+B:

head -> 1 -> 2 -> 3 -> a -> b -> c -> d -> None

A*B:

head -> 1 -> a -> 2 -> b -> 3 -> c -> d -> None

No 2 - Stack

Sebuah robot menerima sekumpulan instruksi dalam bentuk list/array yang berisi perintah "move" dan "undo". - Perintah "move" berarti robot bergerak maju satu langkah. - Perintah "undo" berarti robot membatalkan satu langkah gerakan "move" terakhir yang telah dilakukan.

Tugas Anda adalah membuat fungsi is_valid_commands(commands) dengan input berupa array (bukan yang numpy/sympy) menggunakan struktur data Stack untuk menentukan apakah urutan perintah yang diberikan valid.

Hasil output: 1. Perintah dianggap tidak valid (False) jika terdapat perintah "undo" ketika tidak ada langkah "move" yang bisa dibatalkan. 2. Jika seluruh urutan perintah berhasil diproses tanpa melanggar aturan di atas, maka kembalikan nilai True.

Contoh:

  • Input: ["move", "move", "undo", "move"] -> Output: True
  • Input: ["undo", "move"] -> Output: False (karena undo dilakukan di awal saat belum ada gerakan)
  • Input: ["move", "undo", "undo"] -> Output: False (karena undo kedua tidak memiliki pasangan move yang tersisa)

Setelah membuat fungsi tersebut, jalankan kode berikut untuk menguji beberapa contoh perintah yang valid dan tidak valid.

commands_1 = ["move", "move", "move", "undo", "move", "undo", "move", "move", "undo", "move"]
commands_2 = ["move", "move", "undo", "undo", "undo", "move", "move", "move", "undo", "move"]
commands_3 = ["move", "move", "undo", "move", "move", "undo", "undo", "move", "move", "undo", "undo"]
commands_4 = ["undo", "move", "move", "move", "undo", "move", "move", "undo", "undo", "move"]

print(f"Hasil perintah 1: {is_valid_commands(commands_1)}")
print(f"Hasil perintah 2: {is_valid_commands(commands_2)}")
print(f"Hasil perintah 3: {is_valid_commands(commands_3)}")
print(f"Hasil perintah 4: {is_valid_commands(commands_4)}")

No 3 - Queue

Sebuah taman hiburan memiliki sistem antrean dengan dua kategori tiket masuk, yaitu Express dan Reguler. Buatlah fungsi get_order(visitors) dengan input array dan outputnya adalah urutan pengunjung yang diterima terlebih dahulu. Gunakan struktur data Queue.

Input: 1. Input berupa array yang tiap elemennya berupa dictionary yang berisi informasi tentang pengunjung (silahkan cari penjelasan singkat tentang Python dictionary di internet). 2. Setiap pengunjung memiliki 3 data: index, jenis_tiket, dan waktu_kedatangan. 3. index berupa integer positif dan bersifat unik untuk setiap pengunjung. 4. jenis_tiket express direpresentasikan dengan huruf "e" dan reguler direpresentasikan dengan huruf "r". 5. waktu_kedatangan berupa integer non-negatif dalam satuan waktu menit.

Ketentuan Pemrosesan: 1. Setiap pengunjung hanya bisa mulai diproses tiket masuknya pada saat atau setelah waktu_kedatangan. 2. Setiap tiket selalu diproses selama 2 menit. 3. Pengunjung dengan tiket Express e selalu dilayani terlebih dahulu sebelum pengunjung dengan tiket Reguler r yang ada di antrean pada saat yang sama. 4. Jika ada beberapa pengunjung dalam jenis tiket yang sama, mereka dilayani berdasarkan waktu kedatangan terawal (First Come First Served). 5. Output akhir berupa array dengan isi index pengunjung yang diurutkan berdasarkan siapa yang diterima terlebih dahulu.

Contoh 1 * Input: 1. Index 101, tiket r (Reguler), datang menit 0 2. Index 102, tiket e (Express), datang menit 1 3. Index 103, tiket e (Express), datang menit 4 * Output: [101, 102, 103]

Contoh 2 * Input: 1. idx: 201, tiket r (Reguler), datang menit 0 2. idx: 202, tiket r (Reguler), datang menit 1 3. idx: 203, tiket e (Express), datang menit 2 * Output: [201, 203, 202]
